# v2 Component Preview

This preview mounts the actual Vue 3 `Croppa` component from `v2/src`. Choose or drop an image, move and zoom it below the fixed viewport, rotate or flip it, remove it, and download the crop. Open **Interaction options** to try replacement and disable controls. Dropping a new file over an existing image requires **Replace image on drop**.
